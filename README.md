# Арктика: деньги и безопасность (октябрь 2026)

Доклад «Северного проекта» для капитанов и берегового офиса: 15 минут + 15 минут Q&A.

- `Arktika_dengi_i_bezopasnost.pptx` — презентация (13 слайдов, заметки докладчика внутри, фирменные цвета и логотип)
- `Arktika_dengi_i_bezopasnost.pdf` — та же презентация в PDF для просмотра
- `build_deck.js` — скрипт сборки (pptxgenjs); нужны `pptxgenjs` и модуль `apply_theme.js` из навыка pptx
- `logo.png` — логотип, увеличенный до 540×360 для презентации; `logo_original.png` — исходный файл (135×90)
- `DATA_REQUEST.md` — какие данные по рейсам нужны для слайда про танкеры

Часть данных взята из пересказов СМИ; список пунктов для перепроверки — на последнем слайде.

## QR-код с контактами
Скрипт `build_deck.js` сам добавляет QR на слайды 1 и 12, если рядом лежит файл `qr_contacts.png`. Сейчас в нём визитка (vCard) докладчика; файл `contacts.vcf` — та же визитка для импорта в телефон.
